# Alchemist Labs

AI Brand Studio. Every constraint is a door, not a wall.

[alchemist-studio.github.io](https://alchemist-studio.github.io/)

## Publishing

This repository serves the Alchemist Labs landing page through GitHub Pages.
Changes pushed to `main` publish from the repository root. The site uses plain
HTML, CSS, JavaScript, and SVG; no build step is required.

The site includes Oxide, Indigo, and Carbon palettes and responsive desktop
and mobile layouts. DM Sans is bundled locally under the SIL Open Font License;
see [the font license](fonts/DM-Sans-LICENSE.txt).
